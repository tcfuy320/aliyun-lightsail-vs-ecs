**轻量应用服务器以后能换成ECS吗？**

能。轻量支持把服务器数据平滑迁移至ECS实例，也支持先升级到更高配置的套餐。业务规模变大后再迁移，是官方明确支持的路径。

**轻量的套餐流量用超了怎么办？**

**为什么服务器装好网站后访问不了？**

**个人博客有必要买ECS吗？**

没必要。博客属于典型的单机低流量应用，轻量套餐的配置和流量足够，价格更低，可视化控制台对新手也友好。
